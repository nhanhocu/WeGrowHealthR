# Clinical cases with sparse, irregular visits (simulated)

Sixty children seen in a paediatric clinic at irregular intervals, with
referral group and gestational age, for Book 1 Part II and broken-stick
examples. Generated by `wgh_simulate_clinical_cases(60, seed = 2024)`.

## Usage

``` r
clinical_cases
```

## Format

A data frame with `pid`, `sex`, `group`, `gestational_age`, `age`,
`age_corrected`, `height`, `weight`, `bmi`, `haz`, `waz`, `baz`.
