# Colour palettes used by the package

Colour palettes used by the package

## Usage

``` r
wgh_palette(name = c("okabe", "sex", "bmi", "status"))
```

## Arguments

- name:

  `"sex"`, `"okabe"`, `"bmi"` or `"status"`.

## Value

A named character vector of colours.

## Examples

``` r
wgh_palette("sex")
#>      Male    Female 
#> "#0072B2" "#D55E00" 
```
