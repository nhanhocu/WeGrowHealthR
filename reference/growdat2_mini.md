# Book 2 teaching cohort, small version (simulated)

A random 3,000-child subset of the full Book 2 cohort generated by
`wgh_simulate(30000, preset = "wgh_like", seed = 2026, style = "book2")`.
Column names follow Book 2 (`schoolyear`, `bmiz`). The full cohort is
available with
[`wgh_download()`](https://nhanhocu.github.io/WeGrowHealthR/reference/wgh_download.md).
`growdat2_mini_truth` holds the true child-level parameters (size,
timing, intensity, phenotype, APHV, PHV).

## Usage

``` r
growdat2_mini

growdat2_mini_truth
```

## Format

Data frames. See
[`wgh_simulate()`](https://nhanhocu.github.io/WeGrowHealthR/reference/wgh_simulate.md)
for the columns.

An object of class `data.frame` with 3000 rows and 14 columns.
