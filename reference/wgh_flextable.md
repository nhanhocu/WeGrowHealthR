# Publication-style flextable

Publication-style flextable

## Usage

``` r
wgh_flextable(df, caption = NULL, digits = 2, merge_col = NULL)
```

## Arguments

- df:

  A data frame.

- caption:

  Table caption.

- digits:

  Decimals for numeric columns.

- merge_col:

  Optional column whose repeated values are merged.

## Value

A `flextable` object.

## Examples

``` r
if (requireNamespace("flextable", quietly = TRUE)) {
  cl <- wgh_classify(growdat)
  wgh_flextable(wgh_prevalence(cl, "obesity", by = "sex"), caption = "Obesity by sex", digits = 1)
}
```
